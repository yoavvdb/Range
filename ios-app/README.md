# Range for iOS (Simulator)

The web app, bundled inside a native iOS shell (Capacitor). It runs from the files in the app, not from the web page.
Your account and data still live in Supabase, and the workout feed is read from the web, so it needs internet.

## Run it in the iPhone Simulator (on a Mac with Xcode)

    cd ios-app
    ./run-simulator.sh                  # iPhone 16
    ./run-simulator.sh "iPhone 15 Pro"  # another device

Or open it in Xcode: `npm install && ./sync-web.sh && npx cap sync ios && npx cap open ios`, then press Run.

After changing the web app, run `./run-simulator.sh` again (it rebuilds and copies everything).

## What is where

- `www/` – the built web app (generated by `sync-web.sh`, not committed)
- `ios/` – the Xcode project (committed)
- `capacitor.config.json` – app id `app.range.mobility`, name, status bar

Before the App Store: change the app id to one you own, set a signing team in Xcode, add the app icon and launch screen.
